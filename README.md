# MINATO PACK(食品容器卸売店のHPサンプル・架空)

架空の食品容器卸売店を題材にした、ホームページ制作のサンプルです。商品をカートに入れて購入手続きまで試せます(実際の決済は行われません)。

- 公開URL: https://sample-hp-youki.vercel.app
- 内容(店名・料金・お客様の声・住所など)は、すべて架空です。実在の企業・店舗とは関係ありません。
- HTML・CSS・JavaScriptのみで作っています。APIキーや外部サービスは使っていません。
- 写真は Unsplash のフリー素材です(出典はページ下部に記載)。
- 制作: Aki(Claude Codeで制作)
